# Nhận xét implementation — 9 October 2026

Source: the **Nhận xét** tab in the Mộc Bàm website brief, including all 29 embedded reference screenshots. The other brief tabs are not copied into the repository.

## Delivered

- Admin catalog: edit, duplicate as a draft, guarded deletion, text/category/visibility/stock filters, low-stock indicators, sold counts, and real priced variants with atomic inventory. Optimistic revision checks prevent stale edits from undoing new orders.
- Orders/customers: readable existing MB order codes, exact customer-history links, payment reconciliation, returned status, refund recording, and an explicit decision to restock only saleable returned goods. Damaged returns can be refunded without restocking.
- Promotions: shop-wide, selected-product, and private customer vouchers; fixed or percentage reductions; usage/status/search filters; scheduled activation; expired-create validation; recipient selection and editable email drafts. Eligibility and discounts are enforced in checkout SQL, including variants.
- Finance: Vietnam calendar periods, refresh, charts/tables/top products, GMV, merchandise net revenue, cancellations/returns/discounts/shipping, paid completed-order AOV, payment breakdown, actual dated collections/refunds, and CSV exports even when empty. Private unit-cost snapshots and exact eligible-line discount snapshots support gross profit. Missing historical costs/allocation remain unknown rather than invented. Damaged-return costs remain expenses; saleable restocked returns reverse inventory cost.
- Traffic: separate GA4 reporting with historical metrics, sources, landing pages, devices, realtime activity, and a true sequential funnel. Admin-only server calls use read-only Google credentials; disconnected/error states never display fabricated traffic. CSV export is available.
- Content: grouped searchable editors for homepage/about/policies, seven revised policies, post cover/video/inline media upload/change/removal, and public media access only for published references.
- Storefront: home navigation, accessible hover/keyboard/mobile policy menus, one selected policy at a time, the MỘC BÀM name and requested tagline, selected variants throughout cart/checkout, and estimated shipping labels until an address is known.
- Support: signed-in customers can send persistent messages directly to staff without a second handoff form. Staff can search, see customer/order context, reply, and resolve threads. Message ownership is enforced in SQL; reads paginate beyond Supabase's default cap and stale polls cannot erase acknowledged messages.
- Shipping/settings: province/ward delivery zones with an editable fallback fee; the server recomputes and snapshots the fee. Transfer availability and account completeness are visible in settings.

## Deliberate decisions and prerequisites

- Use configured province/ward fees rather than claiming precise kilometre-based delivery pricing without a routing/carrier source. This keeps the displayed quote reproducible on the server.
- Use a clear seven-day return policy rather than conflicting seven-day/48-hour cutoffs or mandatory unboxing video as the only accepted evidence. Distinguish damaged returns from saleable stock.
- Privacy acknowledges necessary hosting/authentication/delivery providers. Terms claim rights only in Mộc Bàm's own content and respect third-party/open-source licences.
- Voucher email actions prepare editable drafts; the app does not silently send messages.
- Bank transfer remains disabled until actual bank details are configured; the release does not invent them.
- Live traffic requires `GA_PROPERTY_ID` plus a Google reporting service account (Viewer access to the GA4 property and the Analytics Data API enabled). Set `GA_SERVICE_ACCOUNT_EMAIL` and `GA_SERVICE_ACCOUNT_PRIVATE_KEY` only in server environment settings. The short-lived `GA_ACCESS_TOKEN` fallback is also supported. No Google credentials are committed. Operating/ad/carrier expenses are not available, so net profit and ROAS are not fabricated.
- Enter product cost before future sales to populate new immutable snapshots. Existing orders are not backfilled from today's costs.
